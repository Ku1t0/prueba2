
# Evaluacion2

Aplicacion Python que utiliza la API de GraphHopper
para calcular rutas entre dos ubicaciones.

## Funciones
- Mensajes en español.
- Distancias con dos decimales.
- Salir con s o salir.
- Instrucciones del viaje en español.

## Ejecutar
1. Instalar requests: pip3 install requests
2. Ejecutar: python3 clima2.py
3. Ingresar la clave API de GraphHopper.
4. Ingresar origen y destino.
